| HJ10 | Han Jiaming | **Repository Maintenance Agent for Small Open Coding Models** | Coding Agents | Difficulty: intermediate to advanced \| Main resource: language model inference and CPU tests. Build an agent that completes small multi-file changes in unfamiliar repositories. Students implement repository mapping, symbol retrieval, change planning, incremental patching, and test-driven recovery. Evaluate hidden-test success and regressions to establish how much agent scaffolding improves the same small coding model. |
