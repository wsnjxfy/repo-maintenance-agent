## 本轮范围

只做一个受信任的三文件 Python 教学任务，真实运行结构分析、符号查找、补丁、测试失败与修复、独立验收。决策采用清楚标注的预设脚本；不安装依赖、不下载模型、不搭建服务。一个网页报告用于观察执行轨迹，项目的核心是 Python 控制循环。

教学例子保留“超时配置”主题，但进一步收缩为构造请求字典，不实现真实 HTTP、文件配置解析、argparse 命令行或重试。`config_value` / `cli_value` 是两种来源的抽象输入；`cli.py` 是集成层。这样能集中解释跨文件参数传递和失败恢复。

## 设计理由

- 模型/策略通过 `next_action(history)` 提出工具操作，与控制器分开，便于下一层替换。
- 原始 fixture 不被修改；每次运行创建新副本，并保留 JSONL、diff、评测和报告。
- 首轮补丁故意使用有缺陷的 `or` 合并；真实可见测试暴露零值/bool 错误，脚本再应用预设正确修法。
- 重新编辑会使之前的测试通过记录失效。控制器只接受最新工作区已有通过测试的完成请求。
- 隐藏示范检查只在控制循环停止后独立执行，不交给策略。初始回归与最终回归对照，以识别新增回归。
- 教学验收源码公开、策略已知修法、只有一个任务，所以不能用于证明模型能力、检索收益或泛化。
- 使用标准库降低入门成本。工具白名单与新进程不是 OS 沙箱，后续跑陌生仓库前需要补齐隔离。
