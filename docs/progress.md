- 通用 OpenAI 兼容配置：`LLM_API_KEY` / `LLM_MODEL` / `LLM_BASE_URL` / `LLM_JSON_MODE` / `LLM_PRICE_*`（`DEEPSEEK_*` 仍兼容）

- JSON 围栏与散文包裹的容错解析；`json_mode=auto` 遇 400 自动关闭
